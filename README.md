# 묘신령 卯神靈 — AI 사주 웹앱 (프로토타입)

츤데레 삼색 고양이 신령 **묘신령**이 사주(四柱)를 풀어주는 모바일 퍼스트 웹앱입니다.
빌드 결과물인 `index.html` 파일 하나만 있으면 외부 이미지·CDN·서버 없이 완전히 동작합니다
(캐릭터 일러스트는 base64로 내장).

- 배포 주소: https://yjlove5277-tech.github.io/myoshinryung-saju/
- 만세력 계산은 100% 클라이언트 로직이라 서버 비용이 없습니다.

## 동작

1. 이름(선택)·생년월일(양력)·태어난 시간·성별·고민 주제를 고르고 **묘신령에게 보기**를 누릅니다.
2. 1900~2050년 만세력으로 년·월·일·시 8글자와 오행 분포를 계산합니다.
3. 오행 방울·기본 팩폭·위로 한마디·오늘의 한 줄이 나오고, 9:16 팩폭 카드를 PNG로 저장할 수 있습니다.
4. 심화 리포트(재회·재물 등)와 부적 배경화면은 준비 중인 유료 영역입니다(현재는 안내만 표시).

## 파일 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 배포되는 단일 파일 (빌드 산출물, 직접 수정해도 동작) |
| `src/template.html` | UI·스타일·화면 로직 템플릿 (`{{IMG_MAIN}}` 등 자리표시자 포함) |
| `src/engine.js` | 만세력 엔진 (연주·월주·일주·시주, 절입 시각 반영) |
| `src/terms_table.js` | 1900~2050 24절기 절입 시각 테이블 |
| `src/data.js` | 오행별 팩폭·위로 대사 데이터 |
| `src/build.py` | 빌드 스크립트 (`python3 src/build.py`) |
| `assets/` | 캐릭터 일러스트 원본(웹용 JPG) |

`src/` 쪽을 고쳤다면 저장소 루트에서 `python3 src/build.py` 를 실행해 `index.html` 을 다시 만들고,
바로 `index.html` 만 고쳐도 배포에는 그대로 반영됩니다.

## 계산 검증

- 일주: 1900-01-01 ~ 2050-12-31 **55,152일 전수**를 sxtwl 2.0.7과 대조 → 불일치 0건
- 시주: 12시진 2,268케이스 대조 → 불일치 0건
- 연주·월주: 절입 **시각** 기준이라 일 단위 비교에서 나오는 차이는 절기 당일 경계 처리 차이입니다.
